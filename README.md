# ヨツマド (Yotsumado)

4つのペインでフォルダを行き来できる、自分好みのファイルエクスプローラー（Electron製・Windows向け）。旧名称は MyExplorer です。

## 対応環境・インストール

- **Windows専用（64bit / x64）**です。macOS・Linuxには対応していません。
- 配布用インストーラー：[Yotsumado-Setup-1.0.0-win-x64.exe](releases/Yotsumado-Setup-1.0.0-win-x64.exe)
- ダウンロードしたexeを実行してインストールしてください。配布版の利用にNode.jsは不要です。
- ファイル名の `win` はWindows用、`x64` は64bit版を表します。

## レイアウト

```
┌──────────┬────────────────────────────┬─────────────┐
│          │ [Tab1][Tab2][+] 🗂削除      │             │
│ クイック  │  ペイン1  │  ペイン2       │  プレビュー  │
│ アクセス  ├───────────┼────────────────┤  （開閉可） │
│ ドライブ  │ [Tab1][+]  │[Tab1][Tab2][+]│             │
│ 特殊場所  │  ペイン3  │  ペイン4       │             │
└──────────┴────────────────────────────┴─────────────┘
```

## 開発用セットアップ（ソースから起動する場合）

### 必要なもの
- [Node.js](https://nodejs.org/) v18以上（LTS推奨）

### 手順

```bash
# 1. このフォルダに入る
cd smart-explorer

# 2. 依存パッケージをインストール
npm install

# 3. 起動！
npm start
```

### exeにビルドする場合

```bash
npm run build
# → dist/Yotsumado-Setup-1.0.0-win-x64.exe が生成されます
```

## 操作方法

### マウス
| 操作 | 動作 |
|------|------|
| シングルクリック | ファイル選択 + プレビュー |
| ダブルクリック | フォルダを開く / ファイルを既定アプリで開く |
| タブ右クリック | ロック・ロック解除・タブを閉じる |
| 「ロック以外削除」ボタン | ロックしていないタブを一括削除 |
| 🔒 アイコン | ロック済みタブの目印 |

### キーボード
| キー | 動作 |
|------|------|
| `Alt + ←` | 戻る |
| `Alt + →` | 進む |
| `Alt + ↑` | 上のフォルダへ |
| `Ctrl + T` | 新しいタブ |
| `Ctrl + W` | タブを閉じる（ロック中は無効）|
| `Ctrl + P` | プレビュー開閉 |
| `1` / `2` / `3` / `4` | ペイン切替 |

## 機能

- **4ペイン固定**（左クイックアクセス・右プレビュー）
- **各ペインにタブ**（追加・ロック・一括削除）
- **ファイル一覧**：ファイル名・サイズ・更新日時のみ（カラムでソート可能）
- **プレビュー**：画像・テキスト・ソースコード対応・開閉可
- **クイックアクセス**：ドラッグなしで「＋ 追加」ボタンで登録、✕で削除
- **ドライブ一覧**：C:\, D:\ ... 自動検出
- **特殊フォルダ**：ダウンロード・デスクトップ・ゴミ箱
